Image Vault

A shared gallery: everything uploaded here is visible to everyone. You can delete only the images you added.

Setup required Open index.html and paste your Supabase project URL and public key at the top of the script, then reload.

Accepted: PNG, JPG, GIF, WebP, AVIF. Max 5 MB per image. Uploads are public.

Use a direct link that ends in .gif, .png, .jpg or .webp. Discord links expire, so for GIFs you want to keep, upload the file instead.
